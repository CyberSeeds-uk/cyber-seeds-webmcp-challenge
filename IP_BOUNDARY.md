# Cyber Seeds Challenge IP Boundary

This repository is an intentionally isolated,
synthetic demonstration created for the OpenAI
WebMCP Challenge.

It does not contain or depend upon:

- the Cyber Seeds production platform
- production household records
- proprietary assessment methodology
- proprietary scoring or weighting systems
- internal control catalogues
- practitioner operating systems
- safeguarding decision systems
- institutional evidence infrastructure
- private databases
- production authentication systems
- production deployment configuration

No code is imported from private Cyber Seeds
repositories.

The public project demonstrates only a general
human-agent interaction pattern:

1. an agent discovers structured capabilities;
2. read-only inspection is permitted;
3. state-changing action fails closed;
4. the human explicitly approves a specific request;
5. approval is bounded and single-use;
6. the agent retries;
7. the action succeeds only if the approval remains valid.
